Rust scratchpad

Write a whole program with a main function and run it. Stop ends a long-running program by shutting down its worker.

Experimental: this is a 2024 development build of Rust (1.78) and Miri, published by the rubri project. It runs the standard library only (no crates), it is slow (every step is interpreted, with Miri's undefined-behaviour checks turned off), and a panic ends the program instead of unwinding.
