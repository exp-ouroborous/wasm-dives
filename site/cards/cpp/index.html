C/C++ scratchpad

Write a whole program with a main function, pick C++ or C, and run it. Stop ends a long compile or a runaway program by shutting down its worker.

C++ is compiled without exceptions (this libc++ build has none), so throw and try do not compile. Programs run with WASI: standard input is empty and there is no network or real filesystem.
