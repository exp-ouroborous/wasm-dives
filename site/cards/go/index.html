Go scratchpad

Write a Go program (package main with a main function) and run it. A program that loops forever or deadlocks keeps waiting here — Stop ends it by shutting down its worker.

This is an interpreter, not the Go compiler: programs run slower than compiled Go, and a few things are missing — the min and max built-ins, generic standard-library functions such as slices.Sort, and type inference for functions with two type parameters (write Map[int, string](…)).
