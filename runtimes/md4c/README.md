# md4c 0.6.0

C sources of [md4c](https://github.com/mity/md4c) at release v0.6.0
(commit `7fc1815a5eeba2af7d6120a76202bf59f3b6e6e4`), unmodified, from `src/`.
The build copies them to `run/vendor/md4c/0.6.0/`; the C/C++ card's worker
compiles them with the Markdown engine (`site/run/cpp/engine-host.mjs`).
